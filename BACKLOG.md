# Backlog

Ideas agreed on but left out of v0.1.

- **Project and mentee files.** Concept files for a project or a person mentored, linked from entries, so work on one initiative or one person's growth reads as a thread across months.
- **Retroactive backfill.** At setup, fill the last months from the sources in batches, so a new user starts with history instead of an empty log.
- **Chat recipe (Slack, Teams).** Help given, technical discussions and kudos. Left out because of noise and the privacy rules it needs.
- **More sync targets.** Confluence, Google Docs, Claude Docs, spreadsheets. Same one-way model as Notion.
- **Remember rejected candidates.** Keep a local list of what the person turned down, so overlapping periods (a re-run, a backfill) do not show them again.
- **Role and size fields.** Optional `role` (led / contributed) and `size` (large / medium / small) per entry, if beta testers ask for them.
